## Ranked skill defects

1. **Blocker inflation for judged (unmeasured) a11y issues.** Placeholder-only labels were Blocker in A, B and C; the 1.48:1 input border was Blocker in B and C (key: Major). Cause: SKILL.md:17 defines Blocker as "accessibility failure" with no evidence bar; :146 gates only measured checks. *Fix:* "Blocker needs a measured WCAG AA fail or a cited Apple MUST; judged a11y issues cap at Major; 1.4.11 applies to a border only when it is the field's sole identifier."
2. **Dead-control severity is inconsistent across runs.** A filed dead Remove/Share/Generate/Submit as 2 Blockers; C sent the same no-handler controls to Unverified. Cause: SKILL.md:19 scopes the development carve-out to App Review 4.1/4.2 only. *Fix:* "With release_stage development, a missing handler is Major plus an Unverified 'confirm wiring' line; Blocker only at release."
3. **Material vs Liquid Glass conflation.** D's fix "keep materials for chrome" contradicts visual.md:221; the answer key item 1 calls `.ultraThinMaterial` Liquid Glass. *Fix:* add to visual.md or slop-catalog: "`.ultraThinMaterial`/`.regularMaterial` are standard materials, allowed in content (flag only when nothing sits behind to blur); the (26+) MUST targets `glassEffect` in content". Correct key item 1 to match.
4. **Hard-coded colour under-rated when its contrast passes.** D #10 was Minor; visual.md:153 requires light/dark/increased-contrast variants. *Fix:* in the colour pass, "a literal colour with no appearance variants is Major, independent of the computed ratio."
5. **Apple column not copied from the cited line.** A #7 was tagged MUST; writing.md:192 is SHOULD. *Fix:* report-template: "the Apple tag is copied verbatim from the cited reference line; re-check each tag before output."
6. **Screenshot-only Offer reads as a code request** (B: "I'd need the source code…"). *Fix:* report-template Offer: "for screenshot input, phrase fixes as instructions; never state that code is needed."
7. **Transient states missing from B's Unverified** (toast not named; skeleton only as "Loading"). *Fix:* SKILL.md:188: "for stills, list each transient feedback element seen in markup or copy (toast, skeleton, spinner) by name."
8. **Observed skeleton not filed** (A saw `#tide-skel` flash but put it in Unverified only). *Fix:* "a catalog-row element observed even once gets a finding with its measured duration."
9. **Dark-mode severity is unstable** (Major in A, Minor in C). *Fix:* give missing `prefers-color-scheme` on web one fixed default Impact (Minor unless the profile names low-light use).
10. **Speculative Duo finding at Major** (D #5) for an unseen pose. *Fix:* "Duo findings from source alone cap at Minor and go to Unverified with the pose to check."
