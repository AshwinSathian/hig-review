# hig-review

hig-review is a Claude Code skill that reviews UI and UX against Apple's Human Interface Guidelines. Findings are tagged by how strongly Apple states the rule and by impact, and other research only adds to Apple's position, labelled as such. It works for native Apple apps and for the web.

## Install

As a plugin: `/plugin marketplace add AshwinSathian/hig-review`, then `/plugin install hig-review@hig-review`.

Or symlink the repo into your skills folder: `ln -s ~/Documents/Personal/hig-review ~/.claude/skills/hig-review`.
